## 3. 사업일정
- [전체 일정표] 오른쪽 위 **[입력/수정]**: 마일스톤 편집표(행 추가·선택 행 삭제·중요도 필수/핵심/일반) + [엑셀 양식 다운로드] → 채우기 → [엑셀 업로드](일정ID가 같으면 갱신, 없으면 추가) → [저장하기].
- 새 탭 **[사업일정]**: 월 달력(일~토, 1일~말일). [일정 추가]로 일정·일시(날짜/시각/마지막 날)·장소·참석자 등록, 아래 목록에서 [삭제]. 마일스톤 기한도 함께 표시(끌 수 있음). 저장: `pmc/3_사업일정/사업일정.csv`.
- 마일스톤에 `priority`(중요도) 열 추가 — 대쉬보드 '챙길 일'과 [마일스톤] 탭에 필수/핵심 표시, 중요도 필터.

## 4. 사업관리
- [회의록·후속조치]: [회의록 양식지 다운로드] + [회의록 추가] 안의 [양식 업로드 (자동 채우기)] — `app/minutes_template.py`.
- [이해관계자]: 보기 표(비고 버튼 + 메모 칸, 사진 [업로드]/[사진보기]) + [수정하기](행 추가·선택 행 삭제·열 추가·열 삭제·저장) + [엑셀로 다운로드](사진 포함). 연락처 → 휴대전화·이메일(옛 값은 자동 이전). 사진: `pmc/4_사업관리/이해관계자_사진/`. 사용자가 추가한 열은 CSV에도 그대로 열로 들어갑니다(엑셀에서 열을 더해도 반영).

## 5. 성과관리
- [성과점검표] 기본 보기 = **한 화면에 맞추기**(글자 축소, 연도별 2027~2031 목표치 칸 생략 — 같은 값이 '연간 목표치' 행에 있음). [원본 배치]로 바꾸면 이전처럼 가로 스크롤. 3·5번 페이지는 본문 너비 제한 해제.

## 6. 문서관리 (신설)
- [사업 문서함] `pmc/6_문서관리/`: 기본 분류 폴더 9개(바꿔도 됨), 폴더 이동·새 폴더·이름 바꾸기·옮기기·지우기(휴지통 `pmc/_휴지통`), 끌어다 놓기 업로드, 이름 검색. 여기 넣은 문서는 AI 사업비서 검색에 자동 색인.
- [Google 드라이브] `app/gdrive.py`: 내 계정 로그인(OAuth, `config/google_oauth_client.json`) 또는 서비스 계정(.env). 연결되면 사업 폴더·내 드라이브·공유 드라이브·나와 공유됨·최근 파일·검색, [문서함으로 가져오기](Google 문서는 Word/Excel/PPT로 변환), 드라이브에 올리기·새 폴더, 문서함 파일 [Google 드라이브로 보내기]. **실제 계정으로는 아직 검증 전**(가짜 서비스로 코드 경로만 확인).

# v0.8 추가 (2026-10-10) — 로그인 · 회원관리 · 열람 권한 · Streamlit Cloud 자동 업데이트

## 로그인
- 앱을 열면 로그인 화면이 먼저 나옵니다. 최상위 관리자 ID는 `lhc0104`(초기 비밀번호는 전달받은 값, 코드에는 해시만 저장). 첫 로그인 뒤 사이드바 아래 [ID · 권한] › [비밀번호 변경]으로 바꾸는 것을 권합니다.
- 계정은 `pmc/0_공통/계정.csv`(accounts 표)에 저장되고 비밀번호는 PBKDF2-SHA256 해시만 저장됩니다(되찾기 불가, 재설정만 가능). 표가 비어 있으면 최상위 관리자가 자동 생성되며, 환경변수/Secrets `AIKME_ADMIN_ID` · `AIKME_ADMIN_PW` 로 바꿀 수 있습니다.
- 새로고침하면 다시 로그인해야 합니다(브라우저 쿠키를 쓰지 않음).

## 회원관리 (관리자만, 사이드바 아래 [회원관리])
- [계정 추가]: ID · 이름(소속) · 초기 비밀번호 · 권한(관리자/일반) · 메모. 행마다 [권한](권한·이름·메모 변경) · [비밀번호](재설정) · [삭제]. 자기 계정 삭제, 마지막 관리자의 권한 내리기·삭제는 막혀 있습니다.

## 권한
- 관리자: 모든 수정·추가·삭제. 일반: 열람만 — 저장·추가·삭제·업로드 성격의 버튼과 편집표·업로더가 비활성화되고(마우스를 올리면 "열람 권한만 있습니다"), 혹시 뚫리더라도 저장 계층(`storage.check_edit`)에서 다시 막습니다. 내려받기(엑셀·Word·PDF)와 [문제보고] 메모 남기기는 일반 계정도 됩니다.
- 구현: `app/auth.py`, `storage.permission_check`(세션별), `ui._install_view_only_guard()`(Streamlit 위젯 래핑).

## Streamlit Cloud 업데이트
- `streamlit_app.py`: Secrets → 환경변수 복사 후 `app/ui.py` 실행. Cloud 파일 시스템은 다시 배포될 때 git 내용으로 초기화되므로, **PC가 원본이고 Cloud는 보기용**입니다(Cloud에서 고친 내용은 다음 배포 때 사라짐 — Google 드라이브 동기화를 붙이기 전까지).
- `UPDATE_CLOUD.bat`: git add → commit → push(origin/master). Cloud가 1~3분 안에 자동 재배포. `SET_AUTO_UPDATE.bat`: 매일 18:00에 UPDATE_CLOUD.bat 을 돌리는 Windows 예약 작업 등록.
- `AI_ME_v1.bat`: 패키지 검사에 pillow·google 패키지 추가(첫 실행 때 설치).
